# UrduLens Reader

Upload or photograph Urdu text and get editable text back. Images are processed in memory and are not stored.

Part of [UrduLens](https://github.com/abdullahbinmasood702/urdulens), an open benchmark of Urdu OCR engines.
OCR for Urdu is imperfect, especially for Nastaliq print and low-quality photos. Please check the output.
